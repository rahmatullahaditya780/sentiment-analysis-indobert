# Fase 3 - Data Preprocessing

## Tujuan
Membersihkan dan menyiapkan data agar sesuai untuk training IndoBERT.

## Deliverables
- Dataset hasil preprocessing.
- Aturan preprocessing terdokumentasi.
- Output valid untuk tahap training.

## Checklist Selesai Fase
- [ ] Data duplikat dan noise sudah ditangani.
- [ ] Normalisasi teks sudah diterapkan.
- [ ] Tokenisasi dan format input siap untuk model.
- [ ] Dataset hasil preprocessing tervalidasi.
- [ ] Dataset siap untuk fase training.

## Implementasi Awal
- Tentukan pipeline preprocessing yang konsisten.
- Simpan data sebelum dan sesudah preprocessing.
- Uji sampel hasil preprocessing sebelum dipakai untuk training.

## Gate ke Fase Berikutnya
Lanjut hanya jika output preprocessing siap dipakai langsung untuk training.
