# Fase 5 - Model Evaluation

## Tujuan
Menilai performa model dari sisi akurasi klasifikasi dan kualitas prediksi.

## Deliverables
- Metrik evaluasi.
- Analisis hasil evaluasi.
- Rangkuman kekuatan dan kelemahan model.

## Checklist Selesai Fase
- [ ] Metrik evaluasi sudah dihitung.
- [ ] Hasil evaluasi sudah dianalisis.
- [ ] Kesalahan prediksi utama sudah diidentifikasi.
- [ ] Hasil evaluasi terdokumentasi.
- [ ] Model layak dilanjutkan ke inferensi.

## Implementasi Awal
- Gunakan metrik yang relevan untuk klasifikasi sentimen.
- Catat kasus salah prediksi yang paling penting.
- Tentukan ambang kelayakan model sebelum deployment.

## Gate ke Fase Berikutnya
Lanjut hanya jika performa model dinilai cukup untuk penggunaan inferensi.
